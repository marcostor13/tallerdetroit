-La plataforma debe tener la funcionalidad de light o dark según en el navegador, y también tener un switch en el header.

- La plataforma debe ser muy orientada a la mejor experiencia de usuario y accesibilidad para que los formularios se puedan llenar bien, y que los campos se puedan validad para evitar errores.
- debe ser mobile first, y la versión movil debe ser como app.
- debe ser un mono repo, y el cd/ci debe ejecutarse frontend cuando haya cambios en frontend y backend cuando haya cambios en backend.
- en coolify se debe crear 2 recursos, producción y develop. cuando se haga push a la rama develop, debe desplegarse automáticamente en develop, y cuando se haga push a main debe desplegarse automaticamente en production.
- se debe crear skills y agents para claude code para que se implemente la plataforma de manera correcta eficiente, y con buenas practicas, tanto de codificación como de diseño ux/ui.
- utiliza pruebas unitarias y e2e para toda la paltaforma.
